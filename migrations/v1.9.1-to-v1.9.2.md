# v1.9.1 to v1.9.2

Defines the repository block's Verification bullet as exactly one of two
recorded cases: an assured route backed by linked Promise, Oracle, and Witness
records, or a bounded unassured state linked to the Gap that retains the
absence. The presence of a workflow in the repository is evidence, never an
assurance by itself, so an inherited or unqualified workflow no longer selects
the verification route.
