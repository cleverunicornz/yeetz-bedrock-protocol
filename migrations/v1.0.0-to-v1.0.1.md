# v1.0.0 to v1.0.1

Added the reference-discipline rule to every published `AGENTS.md`:

- Repository files are referenced by repository-root-relative path.
- External files are referenced only by full public URL.
- Never reference a local clone, a private checkout, or a machine-local
  path.
- Every reference must resolve for a reader on any machine.

`situation/AGENTS.md` replaces its Link rules section with the full
Reference discipline section; each namespace `AGENTS.md` gains a Reference
discipline section; the protocol root `AGENTS.md` adds the rule to its
Authoring rules.

Alongside this release the publishing repository was renamed to
`yeetz-bedrock-protocol`. Consumers that pin the repository name in their
synchronizer configuration must update it; resolved commit SHAs and file
digests are unaffected.
