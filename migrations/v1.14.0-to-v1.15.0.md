# v1.14.0 to v1.15.0

Organization layer: pull requests, reviews, issues, projects and CI results go through the `github` MCP tools
(github-agent-mcp), and agents read the new organization skill `github` before touching them or waiting for CI.
The skill holds the nine tools, paging and errors, waiting for a run with `gh run watch --exit-status` in the
background, reading a failed run with `actions_read` `failure_summary` and `job_log_tail`, and what the tools
cannot see (other apps' check runs).

Selected by the organization's human authority on 2026-09-29 (github-agent-mcp v0.3.0 in every container that
runs agents).
