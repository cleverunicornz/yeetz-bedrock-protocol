# v1.0.1 to v1.0.2

Adds the private reference class and its behavior rules to every published
`AGENTS.md`.

References now carry a visibility class: in-repo (repository-root-relative
path), public (full URL), or private (declared coordinate
`Private: owner/repo@<ref>#<path>` with an access note).

Private reference behavior: a declared-private reference that cannot be
fetched is a normal, expected state — never an error, never grounds to
stop work, remove the reference, or invent its contents. Access is
environment-dependent; one failed access method does not prove absence of
access. Private content never crosses into a public document.
