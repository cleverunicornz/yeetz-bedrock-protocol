# v1.9.2 to v1.9.3

Defines the failure model explicitly. The orchestrator retries an invoked agent
that died by restarting that same agent with the same prompt, at most three
times, and never adjudicates, reconstructs, or finishes that agent's work
itself. A run that still fails leaves its pull request open and its branch
untouched: Bedrock never opens, closes, merges, or rebranches a pull request
under any circumstance. Re-requesting Bedrock on the same pull request starts a
new run, and a dangling opening checkpoint is superseded by the next run's
opening checkpoint. This removes the earlier rerun-pull-request behavior.
