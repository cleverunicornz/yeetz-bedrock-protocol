# v1.13.0 to v1.14.0

Organization layer: security findings stay in the security vault, never in a repository. A fix for one lands in
one pull request together with its property-level Promise and Oracle (the property the code keeps, never the
attack, a payload, reproduction steps, severity or "is vulnerable"), in every repository, public and private. The
finding, its Candidate and the full Decision stay in the vault; a private repository may cite the opaque vault ID,
a public one never does. This is the protocol's exception for security findings to the one-commit promotion of
Candidate, Decision, Promise and Oracle.

Selected by the organization's human authority on 2026-09-28 (the security harness design, decision O4 and the
Promise-timing ruling); built as infra-v2 D-000115.
