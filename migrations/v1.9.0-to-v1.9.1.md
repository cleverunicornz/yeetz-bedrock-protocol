# v1.9.0 to v1.9.1

Separates pull-request mergeability from agent merge authority. Every trunk
change lands through a pull request, and an agent leaves that pull request open
unless the active task explicitly authorizes that agent to merge the exact pull
request. Review requirements remain an independent branch policy.

Clarifies the upstream-fork boundary: Bedrock does not rewrite upstream-owned
files merely to impose its knowledge projection. That restriction does not
prevent ordinary product changes through the fork's working trunk.
