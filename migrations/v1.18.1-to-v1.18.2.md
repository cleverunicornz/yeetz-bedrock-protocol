# v1.18.1 to v1.18.2

The `implementer` skill triggers on the work, not only on the role. Its description named only the Paseo profiles
that start it, so a session changing repository code without that profile never loaded it and never received its
test-first procedure. It now applies before any agent writes or changes repository code, tests, configuration, or
documentation, whether started under `implementer` or `security-implementer` or changing the repository directly,
and when writing an implementer's brief.

Selected by the organization's human authority on 2026-10-01 (skill observation SO-000018, disposition `org-skill`).

- `skills/implementer/SKILL.md`: trigger-first description covering direct changes as well as the profiles; the
  opening line no longer assumes the agent was started under the profile. The procedure is unchanged.
- `VERSION` 1.18.2, `manifest.json` (implementer digest; every digest re-checked against its file).

Numbered after 1.18.1 (the workbench release in its own pull request). The other role skills (`scout`, `validator`,
`advisor`, `orchestrator`) keep their profile-scoped descriptions in this release.
