# v1.8.0 to v1.9.0

Replaces the designated `fork-operations` skill with the organization's fork
rules in the root organization block: an upstream fork records ownership and
the upstream coordinate, and synchronization and contribution follow those
rules outside Bedrock. Drops the fork documentation projection: on an upstream
fork, README and every other upstream-owned file stay untouched so the trunk
merges cleanly, and the fork's orientation lives only in the root blocks and
`situation/`.
