# v1.12.5 to v1.13.0

Organization layer: skill observation at pull-request time. When a pull request is ready to merge, the agent
requests skill observation (`@unicornz-integrity skill observation requested`), adjudicates every observation
with the human it works for and applies the actioned ones. New organization skill `skill-observation` holds the
procedure: the request, the comment, the adjudication reply format, and where each kind of change goes.
`git-etiquette`: repo-pod commits carry `Lineage-*` trailers, and pull request descriptions end with the
`cvu-lineage pr-footer` line.
