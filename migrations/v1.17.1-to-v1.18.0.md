# v1.17.1 to v1.18.0

Verbs beside the nouns, and the organization circle. The protocol names a small fixed set of verbs — the acts that
make or change records, derived from the learning loop — beside its record classes; a new verb, like a new record
class, takes a protocol Decision. The organization keeps its own knowledge as records in the same schema as a
repository's `situation/`, installed read-only at user level as `org/situation/`, and a skill becomes a verb: a
trigger-first description, a procedure-only body, pointers to records, and its verb in front matter. The `github`
skill is the one worked example; the other skills are unchanged in this release.

Selected by the organization's human authority on 2026-09-29, which approved the verb set after review.

- `templates/root-protocol.md`: the verbs observe, surface, propose, challenge, test, decide, promote, implement,
  bound, plan; record classes and verbs are fixed sets changed only by a protocol Decision; a skill declares the one
  verb it performs.
- `templates/organization.md`: the organization's records live in `org/situation/`; the `org/…` path convention
  (`/etc/cvu/org/…` in a container); the GitHub rule points to its critical invariant I-000001.
- `organization/situation/` (new, published under `organization_situation`): `context.md`, D-000001 (knowledge in
  records, skills as verbs), I-000001 (GitHub work through the github MCP tools, critical), I-000002 (CI waited for
  in the background, read by summary), I-000003 (a list read to its end), and one Reference owned by each invariant
  (tools and blind spots; CI runs; results, paging and errors).
- `skills/github/SKILL.md`: `verb: observe`; trigger-first description; seven procedure steps; pointers to I-000001
  to I-000003 and their References. The tool catalogue, result and error shapes and blind spots moved into those
  References.
- `AGENTS.md`, `README.md`: the organization circle as a content class, its authoring rules and installed-path
  convention, `verb` front matter, the verbs, and the `organization_situation` manifest key.
- `VERSION` 1.18.0, `manifest.json` (organization, github skill and root protocol digests, the new
  `organization_situation` list; every digest re-checked against its file).

Consumers: the org-layer installer copies `organization/situation/` to `org/situation/` beside `org/skills/`. Only
`skills/github/SKILL.md` carries `verb` in this release; the remaining skills gain one as each is converted.
Codex's and NOOA's skill loaders ignore front-matter keys they do not know, so `verb` changes nothing there; for
Claude Code it is unchecked.
