# v1.1.1 to v1.2.0

Replaces `result.json` with Git-native event lineage and defines explicit
closure operations, donor receipts, README lifecycle, and fork ownership.

- Runs are bounded by immutable opening and completion checkpoint commits.
- Every closer/validator/corrector stage has a standardized subject and
  trailers and is pushed immediately.
- Operations are `INITIALIZE`, `BACKPORT`, or `DELTA` independently of phase.
- BACKPORT records donor receipts and preserves collapsed choices as Decisions.
- README is authored last as human orientation.
- `UPSTREAM_FORK` repositories use `main` as upstream mirror and
  `internal/main` as the Bedrock operational trunk.
