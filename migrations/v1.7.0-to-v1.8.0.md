# v1.7.0 to v1.8.0

Removes the runs namespace with its run directories, report files, and
resumption path. A run performs one closure on one pull request branch bounded
by an opening and a closing checkpoint commit; interior commits are completed
units of agent work; run reports are pull request comments; agent transcripts
are archived outside the repository behind a `Bedrock-Transcript` trailer on
both checkpoints. A failed run is never resumed: its pull request is closed with
a pointer to the rerun, which starts a new branch from the head admitted before
the failure. `context.md` gains a `## Closure state` section written only by
checkpoint commits, DELTA reviews the diff from the last closing checkpoint to
the trigger head, and a record may be corrected in place until the first closing
checkpoint that follows it, where immutability begins. Root `AGENTS.md` is three tagged blocks —
protocol, optional organization, and repository — with the new
`templates/repository-block.md` giving the required repository block shape.
Reference discipline is stated once in `situation/AGENTS.md`, and a repository
procedure is a Reference owned by the Invariant or Promise that requires it.
