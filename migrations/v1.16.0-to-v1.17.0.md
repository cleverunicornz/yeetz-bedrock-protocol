# v1.16.0 to v1.17.0

Organization layer: every session keeps a board — the runtime circle of the organization's knowledge layer. A
session's first agent sets the plan and the promises it will deliver, each with an oracle, keeps states current,
and points to detail instead of copying it; sub-agents start from items their parent pre-filled, propose changes to
items they do not own, and a replacement session adopts its predecessor's unfinished items. Boards of the same
repository are readable; other repositories' boards are never read live (work across repositories is contract
first). Harness auto-memory is off; the board is the session's handoff anchor.

Selected by the organization's human authority on 2026-09-29.

- `templates/organization.md`: the rule "Every session keeps its board" (Agents), and a replacement session adopts
  its predecessor's board.
- `skills/board/SKILL.md` (new): when to write what, limits, the per-turn view, sub-agents, replacement sessions,
  other boards, contract-first work across repositories.
- `skills/multi-agent/SKILL.md`: pre-fill a sub-agent's items and pass the delegation label before creating it.
- `VERSION` 1.17.0, `manifest.json` (organization, multi-agent and board digests; every digest re-checked against
  its file).
