# v1.12.1 to v1.12.2

Skill-only release. `skills/workbench/SKILL.md` describes the workbench as it
now runs:

- Every workbench command's time is chosen by the agent, from 60 to 600
  seconds; at that time only that command and what it started are killed.
  The fixed 3-minute cap is gone.
- Claude Code and Codex use the `workbench` MCP tools (`open`, `run`,
  `service_*`, `url`, `desktop`, `status`, `playwright_browser_*`); `run`
  requires `timeout_seconds`. NOOA keeps `self.workbench`; the HTTP shim is the
  fallback for any other harness.

No template, namespace file, or record changes. Adopters resynchronize the
manifest digests through their protocol lock.

These changes were selected by the organization's human authority on
2026-09-27.
